Что происходит под капотом

  • Справочник: контрагенты, договоры, площадки в PostgreSQL, выбираются кнопками
  • Один запрос = один креатив: ключ идемпотентности, повтор после таймаута не создаёт дубль
  • Ошибки ОРД переводятся на человеческий язык (не заполнен ИНН, договор не найден и т.д.)
  • Только официальный API ОРД, без браузерной автоматизации
  • Слой провайдера: смена ОРД или подключение CRM не трогает логику бота
