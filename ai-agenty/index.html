    Как устроена цепочка
    
  
    Каждый агент делает одну проверяемую вещь. Ответ модели не попадает в базу напрямую: сначала его проверяет код.
    
  
    
    
    01 · схема
    Ответ строго по JSON-схеме
    Модель получает схему и обязана вернуть объект по ней (structured output). Лишние поля и неверные типы отсекаются ещё до проверки смысла.
    
    
    02 · цитаты
    У каждого поля есть цитата
    Рядом со значением модель возвращает дословный кусок исходника. Код ищет его в тексте; нет цитаты или значение из неё не следует, значит поле обнуляется.
    
    
    03 · валидация
    Код проверяет факты
    Контрольная сумма ИНН, формат телефона, количество × цена, итог по строкам. Ошибка не правится молча: документ уходит человеку с причиной.
    
    
    04 · связки
    Сторонние API и запись
    Реквизиты по ИНН, справочники, CRM. Результат пишется в БД, таблицу или вебхук с повтором при сбое и журналом по каждому документу.
