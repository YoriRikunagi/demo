# Схема JSON выгрузки модели

```
{
  "schema": 1, "order": "Стол горка", "date": "16.10.2026",
  "edgeNote": "подпись под спецификацией о кромке",
  "hardware": [ {"name": "...", "qty": 6} ],          // фурнитура всей модели
  "blocks": [ Block ]
}
Block {
  "id": "Б1.1", "name": "№1.Шкаф",
  "size": {"w": 562, "d": 594, "h": 1619},            // Ш, Г, В, мм
  "box":  {"x":0,"y":0,"z":0,"dx":562,"dy":594,"dz":1619},   // для общего вида (необязательно)
  "partsCount": 132,                                   // необязательно, иначе считается по панелям
  "hardware": [ {"name": "...", "qty": 1} ],           // фурнитура блока
  "children": [ Block ],                               // вложенные блоки
  "panels": [ Panel ]                                  // панели блока
}
Panel {
  "pos": 7, "name": "№1.Бок", "mat": "материал (по нему группируется спецификация)", "t": 18,
  "qty": 2, "l": 1619, "w": 570,                       // длина, ширина, мм
  "edge": {"l": [низ, верх], "w": [лев, прав]},        // 0/1 — есть ли кромка на стороне
  "edgeMat": "название кромки", "groove": "паз (текст)",
  "role": "side|shelf|top|bottom|back|facade|drawer",  // shelf и drawer дают высоты от низа на виде спереди
  "boxes": [ {"x","y","z","dx","dy","dz"} ],           // по одному на экземпляр, координаты в блоке, мм
  "drill": [ {"x": 320, "y": 50, "d": 8, "depth": 12} ]  // отверстия от левого нижнего угла детали
}
```

Нет `boxes` — в 3D панель не рисуется. Нет `drill` — на детальном листе «Без присадки».
Блок со вложенными блоками получает лист-сборку, блок с панелями — лист с 3D, видом спереди и спецификацией.
