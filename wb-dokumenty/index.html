Документы в карточки Wildberries по артикулу

Сверка таблицы документов с карточками магазина. Меняются только поля с декларацией и сроком, остальное в карточке остаётся как есть. Ниже учебные данные: можно заменить своими.

На боевом запуске карточки забираются из API Wildberries автоматически.

Артикулы сопоставляются без учёта регистра и лишних пробелов.
